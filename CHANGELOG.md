# Changelog

## 2026-11-06: Mobile Discover and data trust

- Replaced the invisible blue Discover action with **Show matching papers** on all three archive pages. The control refreshes the selected-path search and moves keyboard focus to results.
- Added canonical source-verified paper records, lazily loadable monthly JSON shards, a review queue for unclassified topics, and honest per-archive/date coverage counters.
- Added a versioned taxonomy generator from the current three source-specific topic catalogs without changing existing navigation routes.
- Added a live coverage section to Methodology, including last available metadata sync and known gaps.
- Added **Report wrong topic** links to official-paper cards, opening a prefilled GitHub feedback issue for the user to review and submit.
- Added schema and provenance tests, deployment consistency checks and a documented manual QA checklist.

These changes do not imply that exhaustive historical indexing, semantic tagging, hosted collaboration, or all seven planned phases are complete.
