# Litveyra: name and migration notes

**Public product name:** Litveyra  
**Tagline:** Discover research. Trace evidence. Build knowledge.

Litveyra is a coined name for this independent, open-source research discovery and reading workspace. It is not associated with the separate Research Lens website or other similarly named businesses.

## Continuity

- The repository is currently hosted at `pritam-roy-99/researchlens`.
- The existing GitHub Pages URL remains `https://pritam-roy-99.github.io/researchlens/`.
- The JavaScript namespace (`ResearchLens*`), browser storage keys (`researchlens-*`) and legacy URL paths are intentionally retained to keep previously saved reading lists, bookmarks, and integrations working.
- Visible page labels, home-page messaging, app manifest, in-app research assistant name, export headers and logo are now Litveyra.
- Renaming the GitHub repository and changing to a new domain is a **separate migration**. Changing those without redirects, cross-origin data migration, and installation tests can disrupt bookmarks and browser-local data.

## Name clearance

Preliminary exact-name web and GitHub repository searches returned no obvious research platform called Litveyra as of November 2026. This is **not** confirmation of trademark ownership, domain availability, Play Store uniqueness, or legal clearance. Check relevant trademark registries, domains, and app stores before committing to a commercial launch.

## Current limitations

Litveyra is an early-stage open-source research workspace. It does not guarantee exhaustive arXiv coverage, theorem verification or scientific novelty. Hosted account services and hosted inference require separate configuration.
