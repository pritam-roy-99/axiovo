# Axiovo: name and migration notes

**Public product name:** Axiovo  
**Tagline:** From knowledge to discovery.

Axiovo is a coined name inspired by axiom (a foundation for reasoning) and novo (new). It represents this independent, open-source research discovery and reading workspace. It is not associated with the separate Research Lens website or other similarly named businesses.

## Continuity

- The repository is currently hosted at `pritam-roy-99/researchlens`.
- The existing GitHub Pages URL remains `https://pritam-roy-99.github.io/researchlens/`.
- The JavaScript namespace (`ResearchLens*`), browser storage keys (`researchlens-*`) and legacy URL paths are intentionally retained to keep previously saved reading lists, bookmarks, and integrations working.
- Visible page labels, home-page messaging, app manifest, in-app research assistant name, export headers and logo are now Axiovo.
- Renaming the GitHub repository and changing to a new domain is a **separate migration**. Changing those without redirects, cross-origin data migration, and installation tests can disrupt bookmarks and browser-local data.

## Name clearance

Axiovo is a selected coined brand name, but legal trademark, domain and app-store clearance remain necessary. This is **not** confirmation of trademark ownership, domain availability, Play Store uniqueness, or legal clearance. Check relevant trademark registries, domains, and app stores before committing to a commercial launch.

## Current limitations

Axiovo is an early-stage open-source research workspace. It does not guarantee exhaustive arXiv coverage, theorem verification or scientific novelty. Hosted account services and hosted inference require separate configuration.
