ResearchLens: methodology, data coverage & limitations

ResearchLens is an experimental open-source research-discovery prototype, independent from arXiv and SciRate. Last methodology revision: 3 November 2026.

What is indexed?

The static index is a limited rotating set of arXiv metadata, updated on scheduled GitHub Actions runs. Current ingest categories are quant-ph, cs.IT, hep-th, physics.optics, and cond-mat.mes-hall. Cross-listed records may appear. Historical arXiv IDs in a curated list are fetched separately. This is not a comprehensive arXiv mirror. The home page displays indexed paper count, oldest/newest source publication dates, last sync time, and the source categories. The exact live feed is available at feed.json.

Global literature search queries OpenAlex directly, so its searchable corpus is much larger than our local set. It does not mean we independently store or verify all those records.

How related papers are found

The current local shortlist uses token overlap between titles and abstracts, not embeddings or theorem comparison. Topic labels are generated from a transparent multi-label keyword rule set in quantum_topics.py. Abstract and citation matches may miss paraphrases, LaTeX notation, synonyms, missing papers, and proof-level subtleties. Match scores indicate lexical similarity only and must not be interpreted as originality or quality scores.

We distinguish an earlier v1 publication date from a later revision/update date. Even an earlier preprint is not proof that it contains the same theorem.

What AI can and cannot do

The AI Lab produces an immediate, deterministic evidence summary. Its optional WebGPU Qwen model can generate paper explanations and comparison questions from the supplied abstracts only. Model-produced claims are not independently validated and should be treated as questions or hypotheses. No formal proof verification, peer review, or authoritative originality judgments are available. Loading an on-device model requires model downloads from external hosting providers and compatible hardware.

Updates and reproducibility

GitHub Actions is scheduled at 00:37, 06:37, 12:37, and 18:37 UTC. The timestamp in the exported report identifies the analysis time and feed version. Schedules can be delayed or missed. A static GitHub Pages deployment is not a continuously running backend.

Browser-local bookmarks, followed topics, and reading history remain on your device. Clearing browser data may remove them. Export your reading list as BibTeX or JSON as a backup. No public author manuscript submission or permanent DOI minting is currently offered.

Evaluation and next priorities

No quantitative recall or novelty-detection benchmark has been completed yet. We intend to create a hand-labeled set of known prior-art relations and report recall@k, false matches, coverage, and source verification. Until then, the match engine should not be advertised as reliable scientific review.

Near-term development priorities: (1) measured retrieval quality, (2) citation-linked prior-work display, (3) trustworthy full-text retrieval with publisher permissions. Moderated submissions and formal peer review require separate infrastructure, moderation governance, and preservation arrangements.

Contact, errors, and data use

See the public source repository or file an issue for incorrect matches and feature requests. Metadata is drawn from arXiv and optional OpenAlex enrichment; linked manuscripts remain subject to their authors' and publishers' licenses. Platform code is MIT licensed.
