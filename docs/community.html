Discuss research and exchange evidence

Axiovo's community is intended for scholarly questions, paper-specific discussions, reproducibility notes and constructive reviews. The public discussion fallback currently uses GitHub Issues while the hosted researcher-account service is unconfigured.

Discuss a paper

Open a paper in Discover, inspect its original arXiv record and use its discussion link when available. Cite the exact arXiv version and clearly distinguish questions from verified corrections.

Start a public discussion

Use the project's GitHub Issues to discuss a research tool, share feedback, or suggest an evidence-linked feature. A free GitHub account is required for posting.
