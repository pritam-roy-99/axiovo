Privacy and device data

Last updated: November 5, 2026. Axiovo is an independent open-source research website and installable Progressive Web App, maintained in a public GitHub repository. This page describes the currently available site, not a security certification.

What stays on your device

Without optional account features, saved papers, arXiv versions, reading notes, followed authors and topics, researcher profile details, appearance preferences and research questions are stored in your browser's local storage. Other visitors cannot view these settings simply by visiting Axiovo. Browser/device administrators, extensions and scripts running in the same site origin may have access to browser storage, so avoid putting secrets or unpublished sensitive content there.

Some research PDFs are displayed locally in your browser. The public website is not a private encrypted cloud vault. Uninstalling the app or clearing browser/site data can delete local information.

When data leaves your browser

Searching and browsing can contact arXiv, OpenAlex, bioRxiv, Semantic Scholar, GitHub and their content-delivery services. Search terms, paper identifiers and standard network data (such as IP address) may be visible to those services under their own privacy policies. The Research Assistant may call a locally running Ollama service or optional external model services when the relevant feature is enabled. The website also loads external resources, including MathJax and PDF-related libraries, where used.

Axiovo is hosted on GitHub Pages; GitHub may process ordinary website traffic and diagnostic data. This project does not promise that providers collect no logs. Do not upload confidential material to external providers without checking the feature and destination.

Optional community and cloud features

Public discussions currently rely on GitHub Issues and your GitHub account. Optional Supabase account and research-data synchronization features work only if the site owner configures them and you choose to sign in or sync. When enabled and used, selected research data can leave your browser for that configured account. Axiovo does not automatically publish private browser notes as public posts.

Backups and data deletion

Open Settings to export a device-data backup. This JSON file may include personal profiles and unpublished research notes: keep it private. Restoring a backup fills missing data sections but does not overwrite existing sections. Individual export options in the Library remain available. The backup intentionally excludes authentication tokens and third-party site data.

To erase locally stored information, use your browser's site-storage controls for Axiovo. This cannot delete public GitHub comments or data you separately sent to external search, AI or optional cloud providers; manage those through the relevant provider.

Updates, permissions and security limitations

The installed app updates from deployed website code. It ordinarily needs no camera, microphone, contact, SMS or location permissions. The site runs within the browser security model but is not guaranteed free from vulnerabilities. Security checks and source review reduce risk; they do not provide a complete security audit. Updates may be delayed by offline access or cached assets, and backups are recommended before major changes.

Contact and corrections

Report a privacy or security concern using the project issues page. Avoid posting credentials, confidential research or other secrets in a public issue. For urgent sensitive reports, request a private disclosure channel without sharing the vulnerability details publicly.
