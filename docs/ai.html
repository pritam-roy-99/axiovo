Explore the claims. Find the closest prior work.

3. Ask the on-device AI

Experimental · WebGPU

The small open-weight model runs in your browser using WebGPU, if supported. First use downloads model files (potentially hundreds of MB); subsequent visits can reuse cached files. It will not read papers beyond the provided abstracts and evidence.

Evidence report works on all modern browsers. The optional LLM needs WebGPU-capable hardware.

What is actually AI?

Retrieval and matching
Deterministic phrase matching identifies candidate related abstracts, with source links. No claims are automatically verified.
Optional generative model
A small Qwen model can generate explanations and questions using only supplied research context. Hardware and network requirements apply.
Not implemented yet
Formal theorem equivalence, peer review, comprehensive full-text prior-art search, validated originality scoring, and online hosted AI.

Evidence boundaries

All model answers are preliminary. Check source PDFs, technical assumptions, publication dates and independently verified mathematical statements before relying on them.

An AI statement that something is “known,” “novel,” or “wrong” is not evidence by itself.
