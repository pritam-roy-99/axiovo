AXIOVO · PUBLIC SETUP GUIDE

Use Axiovo on Android or install it on your computer

Run the free Axiovo research website on your own device, and optionally connect locally downloaded Ollama models. Axiovo Personal also offers a separate ChatGPT account connection on Windows. Read the platform-specific instructions below.

Android: add Axiovo to your home screen

No APK download, Git or command-line setup is required. This installs the public Axiovo web app shortcut or progressive web app, depending on browser support.

  1. On your Android phone, open Axiovo's homepage in Google Chrome.
  2. Tap Chrome's three-dot menu and choose Install app or Add to Home screen. Wording depends on Chrome version and installability.
  3. Confirm and open the new Axiovo icon from your home screen or app launcher.

Android limitations: This is a web app, not a native Android APK. The public research discovery, reading and browser-based workspace features are accessible, but certain pages require internet access. Offline shell caching does not include the complete paper archive, videos or PDFs. Browser-local data may be lost if Chrome site data is cleared and is not automatically synchronized between devices.

ProofLab AI: The ProofLab interface can open on Android, but the Windows ChatGPT Personal account companion does not run on Android, and Axiovo does not currently provide a supported on-device Android Ollama installation. Local AI actions require a separately configured reachable backend; opening ProofLab alone does not provide offline AI or a ChatGPT connection.

Updates: The web app loads new website versions when they are published and the device reconnects, although Chrome may temporarily display cached resources. It is not an independently distributed Play Store app.

Windows 11: Axiovo Personal, Ollama and optional ChatGPT

  1. Install Node.js 22.12+, Git for Windows and, for offline AI, Ollama.
  2. Open PowerShell (no administrator privileges required for Axiovo). Download the repository:
cd $HOME
git clone --depth 1 --filter=blob:none --sparse https://github.com/pritam-roy-99/axiovo.git
cd axiovo
git sparse-checkout set docs personal

If already installed, run cd $HOME\axiovo followed by git pull --ff-only origin main instead of cloning again.

Start the local app

powershell -NoProfile -ExecutionPolicy Bypass -File .\personal\start.ps1

It opens the Axiovo homepage at http://127.0.0.1:4317/index.html on your own computer. First launch downloads and builds OpenAI's official local ChatGPT DevKit. ChatGPT access still requires an eligible account, browser authorization and an internet connection.

Add a desktop icon

powershell -NoProfile -ExecutionPolicy Bypass -File .\personal\install-shortcut.ps1

Double-click Axiovo Personal to open the homepage. The installer also attempts Start Menu shortcuts, but restricted Windows accounts may block them; the desktop shortcut can still succeed. Existing local Axiovo instances are reused.

Use offline Ollama

ollama pull qwen2.5:3b
ollama list

For localhost Axiovo, configure Ollama's allowed web origin as http://127.0.0.1:4317 and restart Ollama. To run a dedicated server, first quit its existing instance, then open PowerShell:

$env:OLLAMA_ORIGINS = "http://127.0.0.1:4317"
ollama serve

If the port is already occupied, stop the existing Ollama service instead of launching a second instance. Use the ProofLab model discovery button after the server starts. For the publicly hosted site, allow https://pritam-roy-99.github.io as an additional origin if you want browser-to-local access.

More detailed Windows instructions: Axiovo Personal README.

Ubuntu / Linux: local Axiovo + offline Ollama

These steps support the local website and local Ollama inference, not the Windows-only ChatGPT companion.

  1. Install Git and Python 3 with your distribution's package manager:
sudo apt update
sudo apt install git python3

Download Axiovo:

cd ~
git clone --depth 1 --filter=blob:none --sparse https://github.com/pritam-roy-99/axiovo.git
cd axiovo
git sparse-checkout set docs

Install Ollama following its official Linux instructions:

curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5:3b

Serve Axiovo using Python:

python3 -m http.server 4317 --bind 127.0.0.1 --directory docs

Open http://127.0.0.1:4317/index.html and navigate to ProofLab. If your Ollama server blocks this web origin, configure OLLAMA_ORIGINS=http://127.0.0.1:4317 for the Ollama process and restart it. For a systemd installation, set the environment variable using a service override and restart the service; do not start a second server on port 11434.

To run Ollama in a user shell instead of an existing service, stop the existing server first, then run OLLAMA_ORIGINS=http://127.0.0.1:4317 ollama serve.

macOS: local Axiovo + offline Ollama

These instructions run Axiovo locally with downloaded Ollama models. The Windows-specific ChatGPT account companion is not yet available for macOS.

  1. Install Git and Python 3 if not already available.
  2. Install Ollama for macOS (check its current macOS system requirements).
  3. Open Terminal, then run:
cd ~
git clone --depth 1 --filter=blob:none --sparse https://github.com/pritam-roy-99/axiovo.git
cd axiovo
git sparse-checkout set docs
ollama pull qwen2.5:3b
python3 -m http.server 4317 --bind 127.0.0.1 --directory docs

Open http://127.0.0.1:4317/index.html. If browser requests are blocked, quit the existing Ollama app instance, then restart the Ollama server with this allowed origin:

OLLAMA_ORIGINS=http://127.0.0.1:4317 ollama serve

Use a separate Terminal window for the Axiovo Python server. Avoid starting duplicate Ollama servers on port 11434.

Updates and troubleshooting

Windows: the Axiovo Personal launcher checks GitHub for updates on a fresh online launch when the Git checkout is clean and can fast-forward. If already running, stop the app and launch it again. Its Windows login credentials and Ollama models are stored outside the Git checkout.

Ubuntu and macOS: stop the Python server, run git pull --ff-only origin main in your axiovo directory, and restart the Python server.

No Ollama models: check ollama list and verify that the server is running at http://127.0.0.1:11434. Cannot connect: check localhost origin permissions and whether another Ollama process is already running.

Privacy, security and proof verification

A local Axiovo website can store research interactions in your browser. A downloaded Ollama model performs local inference, while ChatGPT's authorized inference sends the approved question and selected material to OpenAI. Existing ChatGPT browser sessions, conversations, passwords and memories are not automatically imported.

Run the local server on 127.0.0.1, not 0.0.0.0, unless you intentionally configure network access. Do not publicly expose the Ollama API or commit credentials to GitHub. Model output is a suggestion, not a mathematically verified proof. Exported Lean 4 drafts require a separate Lean checker.

See the Axiovo methods and limitations page, the ProofLab workspace, and open-source repository.
