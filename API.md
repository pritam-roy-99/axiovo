# Axiovo read-only static metadata API (v1)

The static API is generated by `scripts/build_public_api.py` from source-validated v2 metadata and is **not** a hosted search service. No authorization, accounts, browser notes, saved Library contents, or personal preferences are included.

## Endpoints

- `data/api/v1/manifest.json`: file counts, SHA-256 hashes and the partial-coverage declaration.
- `data/api/v1/arxiv.json`: the available canonical arXiv record/version identities and official landing links.
- `data/api/v1/biorxiv.json`: available bioRxiv DOI/version identities and original links.
- `data/api/v1/chemrxiv.json`: available ChemRxiv DOI identities and original links.

Each JSON file declares `schema_version=1`, source, count and partial coverage. Clients should check hashes in the manifest and avoid assuming the total universe of archive papers is contained in the files.

## Not supported yet

- No `/api/v1/search` service, pagination server, authorization, or per-user collection API.
- No guarantee of complete source-day inventory, full historic recall, or realtime metadata.
- Crossref/OpenAlex external source behavior remains independent of this static API.

## Update and rollback

Regenerate only after `python -m scripts.build_source_v2` succeeds, then run `python -m scripts.build_public_api`. The source shards remain untouched. To roll back, revert the public-API build integration and redeploy the prior verified GitHub Pages artifact. Never clear the client's localStorage/IndexedDB for an API rollback.
